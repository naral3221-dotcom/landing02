# 🤖 랜딩페이지 전문 에이전트 시스템

이 폴더에는 DB 수집형 랜딩페이지 제작에 특화된 3가지 전문 에이전트가 있습니다.

---

## 📦 에이전트 목록

### 1️⃣ **landing-builder** - 랜딩페이지 빌더
**전문 분야:**
- ✅ DB 수집 폼 컴포넌트 생성/수정
- ✅ 반응형 레이아웃 (모바일 우선)
- ✅ CTA 버튼 최적화
- ✅ Tailwind CSS + shadcn/ui 활용
- ✅ 전환율 높이는 UI/UX

**사용 예시:**
```
"상담 신청 폼에 카카오톡 상담 버튼 추가해줘"
"모바일에서 CTA 버튼 크기를 더 키워줘"
"새로운 섹션 만들어서 이벤트 배너 넣어줘"
```

---

### 2️⃣ **ai-matching-dev** - AI 매칭 시스템 개발자
**전문 분야:**
- ✅ 다단계 폼 시스템 구현
- ✅ 후기 매칭 알고리즘 개선
- ✅ 상태 관리 및 데이터 흐름
- ✅ Step별 유효성 검증
- ✅ 프로그레스 바 및 로딩 UI

**사용 예시:**
```
"매칭 시스템에 새로운 질문 단계 추가해줘"
"나이대와 태그 매칭 정확도 높여줘"
"분석 로딩 화면에 재미있는 메시지 추가해줘"
```

---

### 3️⃣ **content-optimizer** - 콘텐츠 최적화 전문가
**전문 분야:**
- ✅ 후기 데이터 작성/편집
- ✅ 마케팅 카피라이팅
- ✅ 전환율 높이는 문구 제안
- ✅ 의료광고 심의 준수
- ✅ 신뢰 요소 강화

**사용 예시:**
```
"30대 볼처짐 후기 3개 더 작성해줘"
"Hero 섹션 헤드라인 더 임팩트 있게 바꿔줘"
"CTA 버튼 문구 5가지 제안해줘"
```

---

## 🚀 사용 방법

### 방법 1: 자동 호출 (추천) ⭐
Claude Code가 자동으로 적합한 에이전트를 선택합니다:
```
사용자: "상담 폼에 체크박스 하나 추가해줘"
→ 자동으로 landing-builder 에이전트 호출
```

### 방법 2: 직접 지정
특정 에이전트를 명시적으로 호출:
```
"landing-builder 에이전트로 CTA 버튼 개선해줘"
"content-optimizer 에이전트로 후기 10개 작성해줘"
```

## 💡 실전 활용 시나리오

### 🎯 시나리오 1: DB 유입 늘리기
```
1. landing-builder → 폼 접근성 개선
2. content-optimizer → CTA 문구 강화
3. ai-matching-dev → 매칭 정확도 향상
```

### 🎯 시나리오 2: 전환율 최적화
```
1. landing-builder → 신뢰 요소 추가 (후기, 인증)
2. content-optimizer → 혜택 문구 명확화
3. ai-matching-dev → 폼 단계 간소화
```

### 🎯 시나리오 3: 콘텐츠 대량 생성
```
1. content-optimizer → 다양한 연령대/고민별 후기 작성
2. content-optimizer → 의료광고 심의 기준 자동 체크
3. ai-matching-dev → 새 후기 데이터 매칭 로직 적용
```

## 📚 추가 자료

- **기술 스택**: React 18 + TypeScript + Vite + Tailwind CSS
- **UI 라이브러리**: shadcn/ui (@radix-ui 기반)
- **프로젝트 구조**:
  - `src/components/landing/` - 랜딩 관련 컴포넌트
  - `src/components/matching/` - AI 매칭 시스템
  - `src/data/review.ts` - 후기 데이터베이스
  - `src/types.ts` - 타입 정의

## 🆘 문제 해결

### 에이전트가 호출되지 않아요
- 요청에 구체적인 키워드 포함 ("폼 추가", "후기 작성", "CTA 개선")
- 또는 에이전트 이름 직접 명시

### 결과가 기대와 달라요
- 더 구체적으로 요청 (예: "20대 후기 3개, 볼처짐 위주로")
- 기존 코드 스타일 유지 필요 시 명시

### 에러가 발생해요
- 파일 경로 확인 (`src/` 폴더 기준)
- TypeScript 타입 오류는 `src/types.ts` 참조
