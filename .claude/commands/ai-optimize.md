# AI 팀 성능 최적화

## 명령어 설명
3개 AI가 협력하여 코드/컴포넌트의 성능을 분석하고 최적화합니다.

## 입력
$ARGUMENTS (최적화할 파일 또는 기능 설명)

## 실행 프로세스

### 1단계: 성능 분석 (병렬)
- **Gemini**: 렌더링 최적화, 불필요한 리렌더 탐지
- **GPT**: 알고리즘 복잡도, 메모리 사용량 분석

### 2단계: 최적화 제안 종합
- 공통 지적 사항 우선 처리
- 트레이드오프 분석 (성능 vs 가독성)
- 벤치마크 기준 제시

### 3단계: 최적화 적용 (Claude)
- React.memo, useMemo, useCallback 적용
- 코드 스플리팅 / 레이지 로딩
- 이미지 최적화
- 번들 사이즈 개선

## 출력 형식
```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
⚡ 성능 최적화 결과
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📊 분석 결과
├── 현재 상태: [설명]
├── 병목 지점: [위치]
└── 예상 개선: [수치]

🔧 적용된 최적화
1. [최적화 내용]
2. [최적화 내용]

📈 개선 효과
- 렌더링: X% 감소
- 번들 사이즈: XKB 감소
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```
