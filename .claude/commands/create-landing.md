# DB 수집형 랜딩페이지 생성

## 명령어 설명
이 명령어는 AI 팀(Claude + Gemini + GPT)을 활용하여 고품질 DB 수집형 랜딩페이지를 빠르게 생성합니다.

## 입력
$ARGUMENTS

## 실행 프로세스

### 1단계: 요구사항 분석 (Gemini)
Gemini에게 `ask_gemini` 도구로 다음을 요청하세요:
- 입력된 비즈니스/서비스 분석
- 타겟 고객 페르소나 정의
- 핵심 CTA 및 전환 포인트 제안
- 필요한 폼 필드 추천

### 2단계: 카피라이팅 (GPT)
GPT에게 `ask_gpt` 도구로 다음을 요청하세요:
- 헤드라인 3가지 옵션
- 서브 헤드라인
- 혜택/특징 섹션 카피
- CTA 버튼 텍스트
- 신뢰 요소 문구

### 3단계: 구현 (Claude - 직접 실행)
분석 결과와 카피를 바탕으로:
1. 컴포넌트 구조 설계
2. 반응형 레이아웃 구현
3. 폼 컴포넌트 생성
4. Supabase 연동 코드 작성
5. 애니메이션/인터랙션 추가

### 4단계: 검증 (병렬)
- Gemini: UX 관점 피드백
- GPT: 코드 품질 리뷰

## 출력물
- `/src/app/(landing)/[name]/page.tsx` - 랜딩페이지
- `/src/components/landing/[name]/` - 관련 컴포넌트
- Supabase 테이블 SQL (필요시)

## 주의사항
- 기존 프로젝트의 Tailwind 설정 및 컴포넌트 스타일 따르기
- shadcn/ui 컴포넌트 활용
- 모바일 퍼스트 반응형 디자인
